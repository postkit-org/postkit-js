Anatomy. Every part is yours to restyle.

Each part carries data-postkit-part, so one set of names styles it in CSS, in a Chakra recipe or with ::part().

Theming. Match your brand. Upgrades still land cleanly.

styles.css · headless

[data-postkit-component="Callout"] {
  border-radius: 14px;
}
[data-postkit-component="Callout"]
  [data-postkit-part="icon"] {
  color: var(--brand);
}

theme.ts · @postkit/chakra

createPostkitTheme({
  callout: {
    base: {
      root: { borderRadius: 'l3' },
      icon: { color: 'brand.solid' },
    },
  },
})

Need more? Swap the icon part, replace the whole view, or run npx postkit eject callout. See Customizing.

Accessibility. Colour is never the only signal.

  • The tone mark is decorative. Give the callout a title when the tone matters to the reader.
  • Body text keeps at least 4.5:1 contrast in every tone and variant.
  • In email, the tone becomes a bar and the title stays in the text, so nothing depends on CSS support.
