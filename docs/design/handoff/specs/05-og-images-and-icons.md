# 05 — Share images and icons

Boards: OgHome, OgComponent, OgDocs, OgNote, OgRelease (1200×630) and SiteIcons.

## 1. Share images

**One template, five kinds**
- White ground, 64px top and 72px side padding.
- Top row: logo (26px) on the left, the kind in mono `fg.quiet` on the right.
- A two-tone title: 76px with no preview, 64px with one. Tracking −0.035em, line height 1.04.
- The page URL in mono at the bottom left, and a 12px brand-gradient band along the bottom edge.

| Kind | Label | Title / grey | Right side | URL |
|---|---|---|---|---|
| Home | postkit.org | "Richer posts." / "Written once, right everywhere." | — | postkit.org |
| Component | Component | "{Name}." / `tagline` (01 §5.4), else the description | 380×300 `bg.subtle` panel with the component's default preview | /components/{slug} |
| Docs | Docs | "{Title}." / `summary` | — | /docs/{slug} |
| Note | Note · {Kind} | `title` / `subtitle` (same split as the article header) | 380×300 cover (gradient or image) | /notes/{slug} |
| Changelog | Changelog | "Postkit {version}." / `subtitle` | "● Latest" badge above the title (only on the latest) | /changelog/{version} |

**How they're made:**
- Generated by OpenGraphs from these templates at build time. Store the template definitions in `apps/site/og/` so they're versioned with the site (01 §2).
- If OpenGraphs isn't ready at launch, `@vercel/og` (Satori) at build time is the fallback, using the same layout.
- The component preview on the share image is a static render of the component, made with the email renderer's static output or a pre-rendered PNG. It's not a screenshot of the page.
- Long titles: at most 3 lines. Shrink in 4px steps down to 56px, then truncate the grey half with an ellipsis. The `fg` half is never truncated.
- Light only, whatever the reader's theme.

**Tags** (next-meta):
- `og:image` (1200×630) and `og:image:alt` (the full title, both halves).
- `twitter:card = summary_large_image`.
- `og:type`: `website` for Home, Components and Docs; `article` for notes and changelog entries.

## 2. Icons

| File | Spec |
|---|---|
| `favicon.svg` | The gradient pill alone, viewBox 30×16, with a transparent ground. It works on light and dark browser tabs. Gradient: `gradientUnits="userSpaceOnUse" x1="0" y1="6" x2="30" y2="10"` with the four brand stops |
| `favicon.ico` | 16 and 32px, rendered from the SVG |
| `apple-touch-icon.png` | 180px: the pill at 62% width on `#1D1D1F`, square (iOS rounds it) |
| `icon-192.png`, `icon-512.png` | Same as the touch icon. 512 is also `purpose: maskable`, with the pill inside the 80% safe zone |
| `site.webmanifest` | name "Postkit", `theme_color` `#FFFFFF`, `background_color` `#FFFFFF`, icons above |

`assets/brand/favicon.svg` is the source. Render the PNGs from it in a build script so they never drift.
