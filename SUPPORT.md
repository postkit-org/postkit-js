# PostKit support

Use [GitHub Issues](https://github.com/postkit-org/postkit-js/issues) for
reproducible bugs and focused feature requests.

Before opening an issue:

1. Check the package README and
   [troubleshooting guide](apps/site/content/docs/troubleshooting.md).
2. Reproduce the behavior with the latest PostKit release.
3. Reduce it to the smallest package and integration boundary involved.
4. Remove credentials, private content, and provider response data that should
   not be shared publicly.

A useful report includes:

- PostKit package names and versions
- Node, browser, framework, React, and Chakra versions as applicable
- Whether the failure occurs during build, server rendering, hydration, or
  client interaction
- A minimal content sample and component configuration
- The expected and observed result

Use a private
[GitHub security advisory](https://github.com/postkit-org/postkit-js/security)
instead of an issue for vulnerabilities.
